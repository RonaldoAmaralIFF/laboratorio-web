Como vamos evoluir o projeto passo a passo

Em vez de misturar HTML, eventos e regras de negócio desde a primeira linha, vamos construir um Gerenciador de Demandas em camadas. Primeiro validamos a lógica pura no Console, depois conectamos à tela e, por fim, salvamos os dados no navegador e organizamos o código em arquivos separados.

Fluxo Unidirecional de Dados (Clique em cada etapa para explorar)

1. Evento do Usuário (main.js)

Tudo começa quando o usuário envia o formulário, digita na busca ou clica em um item. Usamos addEventListener e event.preventDefault() para assumir o controle sem recarregar a página. 

form.addEventListener("submit", (e) => {
  e.preventDefault();
  // dispara atualização de estado
});

    map, filter e reduce
    
            
    // Transforma cada item (mesmo tamanho)
lista.map(t => t.id === id ? { ...t, concluida: true } : t);

// Mantém apenas quem retorna true
lista.filter(t => !t.concluida);

// Consolida em um único valor/objeto
lista.reduce((acc, t) => acc + 1, 0);
