    Socorro! Meu código não funcionou

    Antes de travar, abra o Console (F12) e confira se o seu problema é um destes:

    1. O total apareceu como "01025" em vez de "35.00"

    Causa: Faltou converter o preço com Number(inputPreco.value). Sem isso, o JS junta textos em vez de somar.

    2. Erro "Cannot read properties of null" no Console

    Causa: O querySelector não achou o elemento. Confira se você colocou o # antes do id e se o nome está idêntico ao index.html.

    3. Os itens antigos se repetem toda vez que adiciono um novo

    Causa: Faltou limpar a lista com listaEl.innerHTML = ""; no início da função atualizarTela().

    4. O alerta vermelho não some quando clico em "Limpar tudo"

    Causa: Você colocou classList.add("alerta") no if, mas esqueceu classList.remove("alerta") no else.

    5. Alterei o código e nada mudou na tela

    Causa: Verifique se você salvou o arquivo no editor (Ctrl+S) e recarregou a página no navegador (F5).
