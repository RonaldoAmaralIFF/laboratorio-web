Execução no Navegador, Variáveis e Escopo

O JavaScript é executado pela engine do navegador em conjunto com o HTML (estrutura) e o CSS (apresentação). Para evitar que o carregamento do script bloqueie o parsing do HTML, utilize sempre o atributo defer:

index.html 
<!-- Faz download em paralelo e executa somente após o DOM estar pronto -->
<script defer src="app.js"></script>

Módulo 2

Sistema de Tipos, Coerção e NaN

JavaScript possui tipagem dinâmica e fraca: o tipo pertence ao valor em tempo de execução e não à declaração da variável. O operador typeof inspeciona o tipo de qualquer expressão.

string

Cadeia de caracteres delimitada por ' ', " " ou crases ` ` (template literals).

`Total: R$ ${total}`
number

Inteiros e ponto flutuante (padrão IEEE 754 de 64 bits), incluindo NaN.

42, 25.5, -10, NaN
boolean

Valor lógico utilizado em predicados e estruturas de decisão.

true, false
undefined

Valor automático atribuído a variáveis declaradas sem inicialização.

let x; // undefined
null

Ausência intencional de valor ou referência (por exemplo, retorno de document.querySelector() quando o seletor não encontra nenhum nó).

let itemSelecionado = null;

Módulo 3

Operadores e Estruturas Condicionais

Prefira sempre os operadores de igualdade estrita (=== e !==), que verificam valor e tipo sem acionar coerção implícita.

Comparador ao Vivo

Igualdade Abstrata (==) vs. Estrita (===)

Igualdade Abstrata (evitar)
5 == "5"
true
Igualdade Estrita (recomendado)
5 === "5"
false
if / else if / else e Ternário 
const total = 120;
const limite = 100;

if (total > limite) {
  console.log("Orçamento estourado.");
} else if (total === limite) {
  console.log("No limite exato.");
} else {
  console.log("Dentro do orçamento.");
}

// Operador ternário (atribuição curta)
const status = total > limite ? "Estourado" : "Normal";
Guard Clause (Early Return) 
function adicionarItem(nome, preco) {
  // Valida pré-condições e encerra cedo se inválido
  if (nome === "" || preco <= 0 || Number.isNaN(preco)) {
    return;
  }

  // Fluxo principal limpo, sem else aninhado
  console.log("Item válido:", nome, preco);
}
Módulo 4

Estruturas de Repetição e Funções

Laços permitem percorrer coleções de dados, enquanto funções encapsulam lógica reutilizável. Em JavaScript, funções são cidadãos de primeira classe (first-class citizens), podendo ser passadas como argumento (callbacks).

aguardando

for, for...of e while 
const precos = [10, 25.5, 14.5];

// for clássico (controle de índice)
for (let i = 0; i < precos.length; i++) {
  console.log(i, precos[i]);
}

// for...of (valores diretos)
for (const preco of precos) {
  console.log(preco);
}

// while (enquanto a condição for verdadeira)
let n = 0;
while (n < 3) { n++; }
Funções, Return e Callbacks 
// Declaração com retorno explícito
function calcularSaldo(limite, total) {
  return limite - total;
}

const saldo = calcularSaldo(100, 65.5); // 34.5

// Callback com função anônima
botao.addEventListener("click", function () {
  console.log("Clique detectado!");
});

// Sintaxe equivalente com Arrow Function
botao.addEventListener("click", () => {
  console.log("Clique detectado!");
});

            Módulo 7
            
Erros Comuns e Autoavaliação

            
Principais armadilhas ao iniciar com JavaScript no navegador:

          


          

            

              
                1. Concatenação acidental em somas ("10" + "5" === "105")
                Ver causa
              
              

                Ocorre ao esquecer Number() na leitura de input.value. Sempre converta explicitamente antes de realizar operações aritméticas.
              

            


            

              
                2. TypeError: Cannot read properties of null
                Ver causa
              
              

                document.querySelector() não encontrou o elemento no HTML (verifique se faltou o #, se há erro de digitação no id ou se o script foi carregado sem defer).
              

            


            

              
                3. Leitura de input.value sempre retorna "" (string vazia)
                Ver causa
              
              

                A leitura foi colocada no topo do arquivo (no momento do carregamento da página) em vez de dentro do callback do evento click ou submit.
              

            


            

              
                4. Itens duplicam na lista a cada nova inserção
                Ver causa
              
              

                Faltou limpar o container com listaEl.innerHTML = ""; antes do laço for que recria os elementos <li>.
              

            


            

              
                5. Classe CSS de alerta não desaparece após corrigir os dados
                Ver causa
              
              

                Foi usado classList.add("alerta") no if, mas esqueceu-se do correspondente classList.remove("alerta") no bloco else.
