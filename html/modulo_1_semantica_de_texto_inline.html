Módulo 1: Semântica Inline
Fundamentos de Marcação

Tags Semânticas ao Nível de Texto

As tags de nível de texto modificam o significado intrínseco de palavras ou sentenças específicas dentro de um parágrafo. Lembre-se de uma diretriz de ouro de engenharia frontend: o HTML define o significado lógico; o CSS define a estética visual. Nunca escolha uma tag pelo seu aspeto visual predefinido no ecrã.

<strong>

Importância e Urgência

Representa relevância forte, seriedade ou urgência contextual. Os navegadores renderizam este elemento em negrito, mas o seu propósito real é avisar leitores de ecrã e spiders que o termo é crucial.

Exemplo de Código <p><strong>Erro 500:</strong> Falha na base de dados.</p>
<em>

Ênfase de Pronúncia

Indica ênfase enfática, alterando o sentido fonético da sentença baseando-se em qual palavra recebe a carga falada. Tipicamente renderizado em itálico pelos navegadores.

Exemplo de Código <p>Tens de clonar <em>este</em> repositório.</p>
<code>

Código de Computador

Sinaliza sequências brutas de comandos de terminal, trechos de código-fonte de linguagens ou nomes físicos de ficheiros do sistema operacional.

Exemplo de Código <p>Rode <code>npm run dev</code> no terminal.</p>
<time>

Marcação Cronológica

Permite associar datas descritas para consumo humano a formatos padronizados legíveis por máquina através do atributo vital datetime (norma ISO 8601).

Exemplo de Código <time datetime="2026-06-02">2 de Junho</time>
