Anatomia de URLs e Hiperligações

A World Wide Web é construída sobre o conceito de hiperligações. Compreender como um Uniform Resource Locator (URL) é formado, como passar dados dinâmicos através dele e como invocar protocolos nativos do sistema operativo é uma competência fundamental para a arquitetura de qualquer sistema web moderno.

Relativa vs Absoluta

Absoluta: Contém o caminho completo (protocolo + domínio). Usada para recursos externos.

Relativa: Aponta para um caminho baseado na localização do ficheiro atual. Ideal para navegação interna na mesma aplicação.

<!-- URL Absoluta --> <a href="https://iff.edu.br/sobre">IFF</a> <!-- URL Relativa --> <a href="/sobre">Sobre Nós</a>

Fragmentos (Âncoras)

O símbolo cardinal (#) na URL indica um fragmento. Ele orienta o navegador a fazer scroll automaticamente para o elemento na página que possui o atributo id correspondente.

<!-- Link que aponta para o ID --> <a href="#tabela-precos">Ver Preços</a> <!-- Destino na mesma página --> <h2 id="tabela-precos">Tabela de Preços</h2>

Parâmetros (Query Strings)

Iniciados por um ponto de interrogação (?), os parâmetros são pares de chave=valor separados por &. São vitais para enviar dados ao servidor via GET ou para ler estados no JavaScript (ex: paginação, filtros de pesquisa).

https://loja.iff.br/cursos?area=ti&semestre=2026

Links Especiais

O atributo href não serve apenas para páginas. Pode invocar aplicações nativas do sistema operativo usando protocolos específicos, como clientes de email ou o discador do telemóvel.

<!-- Abre o cliente de Email --> <a href="mailto:suporte@iff.edu.br">Email</a> <!-- Abre o discador telefónico --> <a href="tel:+552299999999">Ligar</a>
