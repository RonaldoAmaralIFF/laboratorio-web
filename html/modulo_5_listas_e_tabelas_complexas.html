Módulo 5: Listas e Tabelas Complexas
Organização de Dados

Listas Semânticas e Modelagem Tabular

Listas organizam conjuntos de itens de forma hierárquica, enquanto tabelas são a estrutura soberana para dados relacionais. A acessibilidade nestes componentes é obrigatória: tabelas mal estruturadas tornam-se impossíveis de interpretar por utilizadores de leitores de ecrã (softwares como NVDA/VoiceOver).

Listas Semânticas

Utilize <ul> para listas não ordenadas (ordem irrelevante) e <ol> para ordenadas (passos de um algoritmo).

<ol>
  <li>Clonar repositório</li>
  <li>Executar npm install</li>
</ol>

Tabelas Complexas

O uso de <thead>, <tbody>, e <tfoot> é mandatório. Sempre defina scope="col" ou scope="row" nos seus <th>.

<th scope="col">Produto</th>

Prática de Laboratório

Refatore o código abaixo para incluir <caption> e a estruturação de seções (thead/tbody):

<table>
  <tr> <td>Item</td> <td>Preço</td> </tr>
  <tr> <td>Computador</td> <td>R$ 3.000</td> </tr>
</table>
